# استوديو بكسل — Pixel Studio

محرر صور ويب متكامل يحاكي المحررات الاحترافية (Photoshop‑like)، بواجهة عربية RTL
وبنية خلفية Python/FastAPI. **لا يعتمد المشروع على أي نموذج ذكاء اصطناعي** —
كل الخوارزميات كلاسيكية (OpenCV/Pillow/NumPy).

---

## 1) التشغيل السريع

المتطلبات: Python 3.10 أو أحدث. يفضل استخدام بيئة افتراضية معزولة.

### Linux / macOS / Git Bash

```bash
# الطريقة الأولى — سكربت واحد ينشئ البيئة ويشغّل الخادم
bash scripts/run.sh            # المنفذ الافتراضي 8000
bash scripts/run.sh 9000       # منفذ مخصص

# الطريقة الثانية — يدوياً
cd backend
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### Windows PowerShell

```powershell
cd backend
py -3 -m venv .venv
& .\.venv\Scripts\Activate.ps1
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

إذا منع PowerShell تشغيل البيئة الافتراضية، نفّذ الأمر التالي مرة واحدة في
جلسة PowerShell للمستخدم الحالي ثم أعد التفعيل:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

ثم افتح المتصفح على:

| الوجهة                  | الرابط                                |
| ----------------------- | ------------------------------------- |
| الواجهة                 | `http://localhost:8000/`              |
| الدليل التعليمي (قراءة) | `http://localhost:8000/help`          |
| تحميل الدليل (ملف)      | `http://localhost:8000/help/download` |
| توثيق Swagger           | `http://localhost:8000/api/docs`      |
| فهرس الواجهة البرمجية   | `http://localhost:8000/api/v1`        |
| فحص الصحة               | `http://localhost:8000/api/v1/health` |

لا توجد أي خطوة بناء للواجهة (لا webpack/npm) — HTML/CSS/JS وحدات ES تُقدَّم
كما هي من المجلد `frontend/`.

## 6) كيفية عمل النظام (باختصار)

1. **النقل**: كل صورة تُرسل base64 داخل JSON (`{"image": …, …params}`) ويرد
   الخادم بنفس الغلاف `{"image", "meta"}` — لا ملفات مؤقتة ولا جلسات (Stateless).
2. **الحساب**: تُحوَّل الصورة إلى مصفوفات `float32` (NumPy) وتُطبَّق العمليات
   رياضيًا ثم تُقتطع القيم مرة واحدة في النهاية للحفاظ على الدقة.
3. **الواجهة**: طبقتا Canvas (صورة + طبقة تفاعلية للقصّ/الرسم/المنظور)،
   سجلّ عمليات بمصغّرات، معاينة فورية مؤجّلة (debounced)، وتراجع/إعادة.
4. **الأخطاء**: استثناءات مخصّصة تُترجم إلى JSON موحّد
   `{"error":{"code","message","detail"}}` بحالات 400/404/413/415/422/500/503.

## 7) الدليل التعليمي داخل الموقع

زر «الدليل» في الشريط العلوي يفتح عارضاً داخلياً يقرأ `frontend/help.html`
داخل الموقع (iframe بنفس الأصل)، ومعه زران: «تحميل الملف» (ينزّل الملف مرفقاً
باسم `pixel-studio-guide.html` عبر `/help/download`) و«طباعة / PDF» (يفتح الدليل
في تبويب مستقل للحفظ PDF بمقاس A4 وأرقام صفحات). الملف واحد مكتفٍ ذاتياً:
كل CSS داخله، يعمل دون إنترنت، عربي RTL بترميز UTF-8.

## 8) التقرير الأكاديمي (اختياري)

إذا أُضيف مجلد `report/` إلى التوزيعة، يمكن بناء التقرير الكامل (فصول مرقّمة،
فهرس، تقنيات وتحديات وحلول) بـ:

```bash
python3 report/build_report.py     # ينتج report/Pixel-Studio-Report.pdf
```

(يستخدم WeasyPrint وخطوط `report/assets/fonts/` العربية.)

على Windows يحتاج WeasyPrint أيضاً إلى مكتبات GTK الأصلية. بعد تثبيت
MSYS2، افتح طرفية **MSYS2 UCRT64** وشغّل `pacman -S mingw-w64-ucrt-x86_64-gtk3`،
ثم أضف مجلد `C:\msys64\ucrt64\bin` إلى `PATH`، وبعدها أعد تشغيل الطرفية
وشغّل أمر بناء التقرير من جديد.
بدون هذه المكتبات يظهر الخطأ `cannot load library 'libgobject-2.0-0'`.
